## 關於本書

2025 年夏天，我的朋友圈被同一個數字刷屏：95%。

麻省理工學院 NANDA 實驗室 2025 年釋出的《生成式人工智慧的鴻溝》(The GenAI Divide) 報告說，過去三年，全球企業在生成式人工智慧上燒了三四百億美元，其中 95% 的專案沒能產生任何能寫進財務報表的價值。幾乎同一時間，另一條新聞在往相反的方向狂奔：矽谷的招聘網站上，一個叫「前線部署工程師」（Forward Deployed Engineer，簡稱 FDE）的崗位，釋出量一年漲了七倍多。OpenAI 在招，Anthropic 在招，YC 孵化器裡一百多家創業公司都在招。

一邊是企業人工智慧專案 95% 的陣亡率，一邊是一個崗位一年暴漲七倍多的搶手度。把這兩條新聞擺在一起看，答案不難猜：**模型已經不稀缺了，能把模型塞進客戶真實業務裡的人，才稀缺。**

我由此對 FDE 這個崗位產生了濃厚的興趣。多年前寫《增長駭客》時，我做的事情本質上和這次一樣：把一個矽谷正在發生、但國內還沒有名字的東西，系統地研究一遍，再誠實地講清楚。這次我也沿用了同樣的笨辦法——翻遍能找到的一手材料：Palantir 早期高管在播客裡的復盤、前員工的回憶錄、風投的行業分析、麻省理工那份報告的原文、幾十份各家公司的招聘啟事、薪酬報告、論壇上從業者的吐槽，以及國內第一批實踐者的經驗談。

這本書就是那個研究過程的完整沉澱。它聊清楚三件事：

- **FDE 是什麼**：這個從 Palantir 情報專案里長出來的角色，如何定義、為何在人工智慧時代爆發
- **怎麼做**：沿著一次真實交付的完整旅程——找對問題、贏得客戶、啟用部署、守住續約、擴大收入、規模化複製
- **誰在做**：165 個真實可查的案例，從 Palantir、OpenAI、Anthropic 到 Harvey、Sierra，再到中國的第一批實踐者

書裡所有資料和案例，都在附錄 C 裡標明瞭出處。整理的過程本身就是學習，我儘量讓每一條引用都經得起核查；如有疏漏，歡迎通過 Issue 指正。

## 為什麼免費公開

這本書首先是我寫給自己的學習筆記。研究一個陌生領域，最好的驗收方式就是把它講成一本別人也能讀懂的書——講不清楚的地方，就是自己沒弄懂的地方。

整理完之後，把它鎖在硬盤裡，多少有些可惜。FDE 在國內還是一個剛有名字的崗位，很多討論還停留在「它是不是換了個名字的售前」。如果這份沉澱能幫正在考慮轉型的工程師看清這個崗位的全貌，幫投身企業人工智慧的創業者少走一段彎路，幫任何一個想弄明白「人工智慧到底怎麼才能在企業裡落地」的人節省幾十個小時的檢索時間，那它公開出來，顯然比躺在我的硬盤裡更有價值。

知識的價值在於流動，而不在於囤積。
